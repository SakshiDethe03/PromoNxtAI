# PromoNxtAI

PromoNxtAI is an AI-powered marketing and promotion platform designed to automate campaign planning, content creation, and multi-channel marketing orchestration.

## Repository Structure

```
PromoNxtAI/
├── backend/            # FastAPI & LangGraph AI agent backend
│   ├── app/            # Main application code (agents, graphs, tools, services)
│   └── tests/          # Suite of unit and integration tests
├── frontend/           # Web UI application
├── data/               # Sample dataset JSON files for businesses, products, & campaigns
├── docs/               # Architecture, API, and workflow documentation
├── .gitignore
├── README.md
└── LICENSE
```
