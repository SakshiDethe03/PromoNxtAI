# PromoNxtAI Workflow Documentation

## Agent Execution Flow
1. **Input Ingestion**: Campaign goals & business context received from user input.
2. **Strategy Planning Agent**: Analyzes product info and targets market channels.
3. **Content Generation Agent**: Drafts copy and social promotional assets.
4. **Human-in-the-Loop Review**: Allows user approval before campaign execution.
5. **Publishing & Tracking**: Distributes content and logs analytics.
